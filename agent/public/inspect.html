Where the tokens go

    Sizes marked ≈ are estimates, about four characters a token. The turns table further down has the exact counts the model reported. Every turn sends all of this again; the cache is what keeps that cheap.

    Versions

    What a turn sends before the conversation changed during this conversation, for example when a plan was approved. Pick a version to see it.

    Settings

    Instructions

    The system prompt, in the parts it is built from. Which parts a turn gets depends on the conversation and on what you allowed.

    Tools

    What the model may call. Each tool's description and input schema is sent on every turn, whether or not it is used.

    Conversation

    Every message so far, as the next turn would send it: what was said, what the model called and what each call returned.

    Turns

    One row for each call to the model, as the model counted it. Cache read is the part sent again unchanged, at a tenth of the price; cache write is new prefix stored for the next turn.
